# fix.bat


`fix.bat` es un script de mantenimiento automatizado para sistemas Windows, diseñado para centralizar tareas comunes de diagnóstico, limpieza y reporte del sistema en una única interfaz de consola (CLI) sencilla y rápida.


## Características Principales

* **Diagnóstico de Hardware:** Reportes detallados de estado de batería (eficacia y duración) y temperatura de CPU.

* **Gestión de Red:** Listado rápido de dispositivos conectados (ARP) e información de red (IPs y MAC) adaptada al idioma del sistema.

* **Mantenimiento:** Limpieza automatizada de archivos temporales y logs del sistema.

* **Reparación:** Acceso directo a comandos de escaneo y reparación de archivos del sistema.

* **Monitorización:** Acceso rápido a herramientas web de diagnóstico de red y velocidad de banda ancha.

* **Autoelevación:** El script detecta automáticamente si no tiene privilegios de administrador y solicita permisos para ejecutarse correctamente.


## Menú de Opciones

Al ejecutar `fix.bat`, accederás a un panel de control interactivo:

1. Reporte ESTADO de BATERÍA

2. Reporte de DURACIÓN y EFICACIA de BATERÍA

3. Reporte TEMPERATURA de CPU

4. MAC - IPs de Dispositivos en RED

5. LIMPIAR archivos TEMPORALES y LOGS

6. Escanear y Reparar sistema

7. Reporte informe de sistema en txt

8. Web - verip.cl para IP Pública

9. Web - fast.com para verificar Velocidad Banda Ancha

0. Salir



## Cómo utilizarlo

1. Descarga el archivo `fix.bat`.

2. Haz **doble clic** sobre el archivo.

3. El script solicitará permisos de administrador automáticamente para realizar las tareas de limpieza y reparación.

4. Selecciona la opción deseada desde el menú y sigue las instrucciones en pantalla.
